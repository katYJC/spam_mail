# Spam Email Classification (Streamlit Demo)

A simple Streamlit demo for spam/ham classification using:
- TF-IDF text features
- Logistic Regression classifier

## Features
- Single email prediction (with probability)
- Batch prediction via CSV upload (`text` column)
- Model metrics + confusion matrix + indicative terms

## Run locally
pip install -r requirements.txt  
streamlit run app.py
